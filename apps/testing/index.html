🧪 API Test

Each section tests one layer of the platform API stack.

1 — Ping

GET /testing/api/ping — confirms the server is routing API requests to this app's api.js.


  


  
  

    
2 — Echo

    
POST /testing/api/echo — sends a JSON body and expects it back. Tests readJson and sendJson.

    
    
    

  


  
  

    
3 — External HTTP

    
GET /testing/api/time — server fetches from worldtimeapi.org. Verifies outbound HTTP from the server works.

    
    

  


  
  

    
4 — Ask Claude

    
POST /testing/api/ask — proxies a prompt to the Anthropic API via the server. Tests ANTHROPIC_API_KEY and the SDK.
